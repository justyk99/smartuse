# Community marketplace submission

**Tagline:** gstack gives you roles. Ruflo gives you a swarm. yk-kit gives you a receipt.

**Description (about 150 words):**

yk-kit starts from one thin line and gives back a spec a fresh session can execute. Its make-prompt skill searches your repo for what a planner needs: reference code, owners from git history, lockfiles, missing tools, past tasks and recorded incidents. It then asks a few multiple-choice questions for what only you know, with Claude's evidence-backed guess as option 1 and "I don't know" always allowed. Three more pieces follow. living-docs updates a developer doc and a user doc per feature after each commit, from the diff. reply-style offers seven reply voices with pros and cons, installed as a Claude Code output style. bash-guard is a hook that denies risky shell commands, even in bypass mode. A Stop hook records token usage per skill run in a ledger, and run-plan tiers deliverables, shows a dry-run routing table, and verifies results with a fresh agent. Styles and skills are instructions; only the hook enforces.

**Keywords:** kickoff prompt, planning, living docs, output styles, bash guard, receipts

**Install:**

```
/plugin marketplace add {{GITHUB_USER}}/yk-kit
/plugin install yk-kit@yk-kit
```
