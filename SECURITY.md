# Security

smartuse ships seven hooks: `bash-guard` (PreToolUse, with the fresh-source gate) and `file-guard` (PreToolUse), `ledger` (Stop / SubagentStop), `until-done` (Stop), `wait-gate` (Stop), `heartbeat` (every event; it records tool names, agent types and timestamps — never tool arguments, file contents or prompts) and `recall` (PreCompact / SessionStart). All are small Python files you can read in a few minutes. None makes network calls.

`recall` and the fresh-source gate read the session transcript (to find your prompts and the model's Reads), the human-only `.claude/smartuse.local.md` and, for `handoff:`, one file inside the repo. What recall prints passes a secret scrub (token prefixes, e-mail addresses, long digit runs) and a 9,000-character cap; its state holds counts and paths, never a command. A cloned repo or an archive can ship its own adapter, so every path value in it is checked as text before any file call: only plain local spellings are accepted (no share, device or automount path), a relative handoff or source never leaves the repo, and a link (a symlink, or a Windows junction or mount point) is refused rather than followed. After a send command matched, any failure to verify denies the call. A hook that misses Claude Code's own hook timeout lets the call through; the gate keeps its work inside a 4 s deadline for that reason. `ledger` reads your session and agent transcripts to sum token usage and writes to `~/.claude/smartuse/`; it never reads file contents other than the transcripts. `until-done` runs the repo's `check:` command only from the human-written adapter, only in fixed shapes or as a script pinned by hash in a root-owned file, with `shell=False`, and prints a redacted tail of its output.

Report a vulnerability by opening a GitHub issue titled `security:` with no exploit details, or email the maintainer address on the GitHub profile. You will get an answer within 7 days.

Known limits: skills and output styles are instructions, not enforcement; the hook rules are regexes and can be bypassed by an actor who edits the hook file. Pair the kit with a deny list in `~/.claude/settings.json` and read-only database logins (see `docs/research/security-profiles.md`).
