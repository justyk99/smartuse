# Security

smartuse ships seven hooks: `bash-guard` (PreToolUse on Bash and PowerShell and, from Claude Code 2.1.314 (confirmed on 2.1.321), Monitor commands; with the fresh-source gate) and `file-guard` (PreToolUse), `ledger` (Stop / SubagentStop), `until-done` (Stop), `wait-gate` (Stop), `heartbeat` (every event; it records tool names, agent types and timestamps — never tool arguments, file contents or prompts) and `recall` (PreCompact / SessionStart). All are small Python files you can read in a few minutes. None makes network calls.

`recall` and the fresh-source gate read the session transcript (to find your prompts and the model's Reads), the human-only `.claude/smartuse.local.md` and, for `handoff:`, one file inside the repo. What recall prints passes a secret scrub (token prefixes, e-mail addresses, long digit runs) and a 9,000-character cap; its state holds counts and paths, never a command. A cloned repo or an archive can ship its own adapter, so every path value in it is checked as text before any file call: only plain local spellings are accepted (no share, device or automount path, no `:` after the drive letter, no part of only dots), a relative handoff or source never leaves the repo, and a link (a symlink, or a Windows junction or mount point) is refused rather than followed. After a send command matched, any failure to verify denies the call. So does a command the gate cannot read cleanly (a very long one, one with heredocs past the scan cap, several command substitutions, a `-c` / `eval` / `iex` / `cmd /c` / `-Command` string handed to another shell, PowerShell typographic quotes or escaped quotes, a PowerShell block comment `<#`, a PowerShell `Start-Process` (or `start` / `saps`) word anywhere, because its arguments are not read): while the job's sources are unopened it counts as a send, and the reason says why. A hook that misses Claude Code's own hook timeout lets the call through; the gate keeps its work inside a 4 s deadline for that reason, and the deadline starts when the hook starts, before the command is scanned. The PowerShell match is coarse: a publish word anywhere in a statement counts, and a form it cannot read (typographic quotes or dashes, an escaped quote, a block comment, a `Start-Process` word, a string handed to another shell) counts as a send while the sources are unopened. It is not claimed to read every PowerShell tokenisation; an adversarial tokenisation pass is listed for 0.6.1. With `publish:` listed and a source unopened (right after a compaction, or before the sources are first opened), a PowerShell command that holds the word `Start-Process`, `saps` or `start` anywhere is denied once until the sources are re-read, including `npm start`, a `$start` variable or the word inside a quoted string. A backtick escape inside that word is not caught yet (0.6.1). The gate reads a command's text, so it cannot see a command built at run time. Some other ways of handing a command to another shell or interpreter are not yet recognised as such (other spellings of the same launchers, text fed on standard input, process substitution, shell functions and traps); they are listed for 0.6.1. In Bash, the join of a line that ends in a backslash does not check what comes before that backslash, so the line after an escaped backslash, or after a comment that ends in a backslash, can be misread (listed for 0.6.1). The frozen older rules are slow on a very long, dense command (when the sources are opened or there is no adapter, such a command can outlast the hook timeout); the contract lists each limit (`docs/notes/recall-design.md`, "Honest limits"). `ledger` reads your session and agent transcripts to sum token usage and writes to `~/.claude/smartuse/`; it never reads file contents other than the transcripts. `until-done` runs the repo's `check:` command only from the human-written adapter, only in fixed shapes or as a script pinned by hash in a root-owned file, with `shell=False`, and prints a redacted tail of its output.

Report a vulnerability by opening a GitHub issue titled `security:` with no exploit details, or email the maintainer address on the GitHub profile. You will get an answer within 7 days.

Known limits: skills and output styles are instructions, not enforcement; the hook rules are regexes and can be bypassed by an actor who edits the hook file. Pair the kit with a deny list in `~/.claude/settings.json` and read-only database logins (see `docs/research/security-profiles.md`).
