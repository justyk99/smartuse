## Carry-over rules
- One heavy job at a time on the laptop, at low priority (the maintainer may be gaming); suites never side by side; never `all.sh` there. The way to lower the priority is not written in the repo: the orchestrator names it in each builder brief. Claude Code stops a background suite when memory runs low: report it, restart only on the maintainer's word.
- Builder briefs: every "as today" claim gets a file:line the builder has read; a bug gets its red case first; name every import allowlist (four suites have one: wait-gate, recall, paid-guard, fresh-gate). No feature of 0.7.4 adds an import.
- `fit_key` is one text in six hooks (heartbeat, bash-guard, ledger, recall, until-done, wait-gate); the wait-gate suite checks the six are equal. A change to one is a change to all six. From 0.7.4, `long_form` and `counter_in` are one text in two hooks (bash-guard, heartbeat); the heartbeat suite checks the two are equal.
- A limit names its switches. For long paths there are two: the `LongPathsEnabled` registry value and a long-path-aware Python. Nothing outside `fit_key` reads the registry.
- A path is matched in every reading: a new look is added beside the old one, never in its place.
- A rule that trusts "the hook alone writes file X" fails: a folder copy, link or junction can plant X without naming it. Fail closed when two sources disagree.
- New code in the paid check, or a changed pattern of an always-on rule, gets a security review round before T3. A deny reason is ASCII, one line, ends "Nothing was spent." and never says how a count can be reset.
- Concurrent writers to one log file lose lines on Windows: one log file per process in any experiment. No experiment writes the registry.
- Tests use a temp `HOME`. The private terms file and `.claude/*.local.md` are never read or printed; `.agents/` and `.codex/` are never touched. Builders stage files by name.
- The release needs T3 (both validates, the interactive scenarios, a fresh review and a security review) and the bare publish scan showing `(0 private)`. Version 0.7.4 goes in both manifests, the CHANGELOG, the badge and the docs in F5, the last feature.
